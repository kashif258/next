# Aurelia Studio

A premium digital studio experience built with Next.js, TypeScript, Tailwind CSS, Framer Motion, and GSAP.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Deploy to Vercel

1. Push the repository to GitHub.
2. Import the project in Vercel.
3. Use the default Next.js project settings.
4. Deploy.
